MovieBox

本地视频管理器 · 一眼看全，点了就播

MovieBox 把散落在多个文件夹、移动硬盘里的视频收集到一个界面里，全部以缩略图呈现， 单击就用你指定的播放器打开。你的文件始终留在你的硬盘上。

下载最新版 查看更新日志

主要特性

统一浏览 多个文件夹、移动硬盘、SMB / NFS 网络盘合并成一个库，网格 / 列表 / 文件夹三种视图。
点了就播 单击缩略图直接用你选的外部播放器播放（IINA / VLC / mpv / QQ 影音 / 系统默认）。
保险箱 把视频原地加密成 .vault，其他程序打不开；MovieBox 打开时自动免密解密。
按人归类 同一演员的视频自动归成一组，先看文件名与元数据，识别不出时再用人脸聚类兜底。
重复检测 按大小分桶 + 首尾哈希快速找出重复文件，加密文件也能和明文副本对上。
收藏分类 自定义收藏分类与颜色，「精选」「稍后再看」默认内置。

关于隐私

MovieBox 不收集、不上传任何数据。没有账号、没有统计、没有遥测。 扫描、缩略图、归类、加解密全部在你自己的电脑上完成。 详见 隐私政策 与 安全说明。

应用为本地工具，不需要联网即可使用；只有「检查更新」时会访问 GitHub Releases。

系统要求

  • macOS（Apple Silicon / Intel）
  • Windows 10 / 11
