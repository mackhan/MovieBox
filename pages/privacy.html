隐私政策

最后更新：2026 年 10 月 19 日

一句话：MovieBox 不收集、不上传、不共享你的任何数据。没有账号系统，没有使用统计，没有崩溃上报。

一、我们收集什么

什么都不收集。MovieBox 没有服务器后台，开发者无法获知你安装了什么、看了什么、库里有什么。

二、数据存在哪里

所有数据都保存在你自己的设备上：

  • 视频文件：始终留在原始位置，MovieBox 不复制、不移动、不上传
  • 视频索引与缩略图：保存在应用数据目录的本地 SQLite 数据库中
  • 收藏、分类、播放次数：同上，仅本地
  • 保险箱密码：只存在于本次运行的内存中，退出即清除；不以明文写入磁盘

三、网络访问

应用默认完全离线可用。仅以下情况会产生网络请求：

  • 检查更新：向 GitHub Releases 请求一次版本清单（latest-mac.yml / latest.yml）， 请求中不包含任何能识别你或你设备的信息
  • 访问你自己添加的网络磁盘（SMB / NFS / AFP）：只连接你手动配置的那个地址

除此之外，MovieBox 不会主动连接任何服务器。

四、第三方播放器

播放功能由你选择的外部播放器（IINA / VLC / mpv / QQ 影音等）完成。 这些播放器有自己的隐私政策，与 MovieBox 无关。MovieBox 只负责把文件路径交给它们。

五、我们不做的事

  • 不要求注册或登录
  • 不读取你的通讯录、位置、相机、麦克风
  • 不向任何分析或广告 SDK 发送数据
  • 不出售、不共享、不对外披露任何信息（因为本来就没有）

六、数据删除

卸载 MovieBox 并删除应用数据目录，即可彻底移除全部本地数据。 如需帮助定位该目录，请通过下方联系方式询问。

七、儿童隐私

MovieBox 不面向儿童，也不会有意收集儿童信息。

八、政策变更

若本政策有实质变更，会更新本页面并修改顶部日期。

九、联系方式

有疑问或建议，请在 GitHub Issues 提出。
